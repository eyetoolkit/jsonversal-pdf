    How to merge PDF files

    1. Drop two or more PDF files into the box above (or click it to browse).
    2. Arrange them in the order you want using the ↑ and ↓ buttons.
    3. Click Merge PDFs. The combined document appears in seconds.
    4. Download merged.pdf to your device.

    Why merge in a browser instead of uploading?

    Upload-based PDF mergers ask you to send contracts, invoices and personal documents to a remote server and trust that they are deleted afterwards. This tool needs no such trust: the merge happens inside this tab, using pdf-lib, the same open-source library many server-side tools are built on.

    • No quality loss — pages are copied as-is; images and text are never re-encoded.
    • No limits — no daily caps, no file-size tiers, no account required.
    • No watermark — the output is a clean, standard PDF anyone can open.

    Frequently asked questions

    Can I merge password-protected PDFs?

    Not with this tool — protected files must be unlocked first. A dedicated unlock tool is on the roadmap; until then, remove the password with your own software before merging.

    Will the merged file keep bookmarks and links?

    Internal links and most annotations are preserved. Bookmarks (the outline panel) are not carried over — the merged document starts with a fresh, empty outline.

    Does the order of files matter?

    Yes. Files are merged top to bottom, exactly as listed. Use the arrow buttons on each file to rearrange before clicking Merge PDFs.
