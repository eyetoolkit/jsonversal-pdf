Frequently asked questions

Can I undo a mistake?

Use Start over to reload the original file. The tool never modifies your source file — it only builds a new document when you export.

Why do some thumbnails look blank?

Some PDFs store page content in ways that need a full viewer to render. If a thumbnail is blank but the page exists, the export still contains the page — the thumbnail is only a preview.

Is there a page limit?

Only your device's memory. Documents with a few hundred pages render and export fine on a desktop; on phones, very large files may be slow.
