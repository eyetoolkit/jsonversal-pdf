Why remove PDF metadata?

Every PDF stores a set of properties beyond what you see on the page: the author's name, the software that produced it, and timestamps. When a contract exported from Word or a report exported from Excel is shared, those fields often carry a real name, a username or an internal file path. Removing metadata is a basic hygiene step before publishing or sending a document outside your organization.

How to remove metadata from a PDF

  1. Drop your PDF into the box above.
  2. Review the fields listed — this is what anyone else can see.
  3. Click Remove all metadata and download the cleaned PDF.

Good to know

  • All information dictionary fields are cleared, and an XMP metadata packet is dropped if present.
  • Visible content, bookmarks and links are preserved — only hidden properties change.
  • Metadata removal is one layer of privacy. For sensitive documents, also consider the Protect PDF tool and remember that this site never receives your file in the first place.

Frequently asked questions

Can I edit metadata instead of removing it?

This tool clears everything for privacy. If you need to set specific fields, any full PDF editor can write them after cleaning.

Does the file size change?

Usually by only a few bytes. The metadata block is tiny compared to page content.

Will the cleaned PDF still open everywhere?

Yes. The output is a standard, fully valid PDF — just without the extra properties.
